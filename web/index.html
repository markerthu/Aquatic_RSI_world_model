How the rays improve themselves

Many rays, one shared habit per species, all learning at once while they compete for the same plankton.

  1. Copy the lagoon: a world model with the same water, plankton and nettles
  2. Imagine 16 practice swims per species, each with a slightly changed habit
  3. Keep what ate more plankton and took fewer stings
  4. Act with the new habit, and repeat every 1.5 s as the lagoon changes

Nothing is pre-trained: reload and they start from zero. The faint lines on the water are the imagined swims; the bright ones scored best.
